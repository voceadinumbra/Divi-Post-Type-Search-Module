Post Type Search Module for Divi

== Description ==
The Post Type Search Module for Divi is a custom module for the Divi theme that allows users to search for specific post types within their WordPress site. This module enhances the search functionality by providing more control over the types of content that can be searched.

== Features == 
- Customizable search for specific post types
- Easy integration with the Divi Builder
- User-friendly interface
- Lightweight and efficient

== Installation == 
1. Download the plugin zip file.
2. Go to your WordPress dashboard.
3. Navigate to Plugins > Add New.
4. Click on "Upload Plugin" and choose the downloaded zip file.
5. Click "Install Now" and then "Activate".

== Usage == 
1. Open the Divi Builder on the page where you want to add the search module.
2. Add a new module and select "Post Type Search".
3. Configure the module settings to specify which post types to include in the search.
4. Save and publish your changes.
